高精度计算器

任意精度十进制 · base-10⁹ 分块内核


            

        

        

            
历史

            
    
        
    
        
    
            
    用法
    
            
      
                
    • 运算符：+ - * / %（% 是 fmod 语义，符号跟随被除数）。
      • 
                
    • 函数：sqrt、abs、pow、exp、ln、log10。
      • 
                
    • 数字：十进制小数、科学计数法（1e20）、以及
                    0x / 0b / 0o 前缀的整数。
      • 
                
    • 精度的上限是 100000 位；但表达式一旦用到超越函数
                    （sqrt / exp / ln /
                    log10，以及 pow 的非整数指数分支），
                    精度另受 1000 位约束 —— 这是内核的算力上限，与界面无关。
                    纯加减乘除的表达式不受这条约束。
      • 
                
    • 进制转换的整数部分精确无损；小数部分若在该进制下无法
                    有限表示，会截断并用 ... 标记 —— 那是「展开被
                    截断了」，不是精确值。
